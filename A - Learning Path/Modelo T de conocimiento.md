¿Qué estrategia sigo para elegir qué aprender entre tantas opciones en desarrollo de software?

Modelo T de conocimiento

Conocimiento que acumula -> conociento que nunca vas a tirar a la basura

Hacerse preguntas:

1. ¿El conocimiento puede ser diferencial en mi trabajo?
Ejemplo negativo: CSS

2. ¿Desde cuando existe este conocimiento? ¿Si lleva tiempo, es obsoleto o está vigente?
Ejemplo negativo: jQuery
Ejemplo positivo: testing

3. ¿Ha cambiado mucho a lo largo de los años? ¿da muchos bandazos?
Ejemplo negativo: Android -> a cambiado mucho con los años

4. ¿Existe algún libro sobre este conocimiento?¿Me servirá ese libro dentro de unos años?
Ejemplo positivo: clean code, refactoring

5. ¿Hay algún referente de este conocimiento? Mejor a nivel mundial

El conocimiento que está relacionado con la tecnologia lo aprendo bajo demanda. Con los proyectos... (con react por ejemplo)
